    Common JSON errors

    • Single quotes: JSON needs "double quotes".
    • Trailing commas: [1, 2, 3,] isn't allowed.
    • Comments aren't allowed in JSON.
    • Keys must be quoted: {"name": "x"}, not {name: "x"}.
