    Paste JSON to format it, validate it with clear error messages (line and column), sort keys or minify it. Everything runs in your browser.

    Runs in your browser. Nothing is uploaded.

    Common JSON errors

    • Single quotes: JSON needs "double quotes".
    • Trailing commas: [1, 2, 3,] isn't allowed.
    • Comments aren't allowed in JSON.
    • Keys must be quoted: {"name": "x"}, not {name: "x"}.

    Questions

    Is my JSON sent anywhere?

    No. Formatting and validation happen in your browser, so it's safe for API keys and private data.
