How it works

  1. Paste the link to your menu. That can be a page on your website, a PDF stored online, or your online ordering page.
  2. Add your business name and choose a colour to match your branding.
  3. Download the table card (A6, 300 dpi). It fits a standard table stand or acrylic holder.

Tips for menu QR codes

  • Test the code with an iPhone and an Android phone before you print a batch.
  • Keep paper menus available. Some customers prefer them, and it helps with accessibility.
  • Will you update prices or change the menu link? Use a Pro dynamic code so you never have to reprint.

Questions

What size is the table card?

It's A6 (105 × 148 mm) at 300 dpi, so it prints sharp at home or at a print shop. You can also scale it up to A5 or A4.

Can I link to a PDF menu?

Yes. Upload the PDF to your website or a file host such as Google Drive (set it to 'anyone with the link'), then paste that link here.

What if my menu link changes?

A free code always points to the same link, so you'd need to reprint. Pro dynamic codes can point to a new link at any time without reprinting.

Is there a watermark?

The free table card shows a small 'etoolbox.co.uk' line at the bottom. The QR code itself is never watermarked.
