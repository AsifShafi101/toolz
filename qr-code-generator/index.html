How to make a QR code

  1. Type or paste your web address. We add https:// for you.
  2. Check the preview, then point your phone camera at it to test it.
  3. Download a PNG for screens and documents, or an SVG for professional printing.

Good ideas for small businesses

  • Google reviews: put a code on receipts and the counter to ask happy customers for a review.
  • Bookings: link straight to your booking page from posters and shop windows.
  • Social media: send people to your Instagram or Facebook page.
  • Flyers: link to an offer page so you can see whether the flyer works.

Questions

Do these QR codes expire?

No. A free code here contains your link directly, so it keeps working for as long as that web page exists. We can't switch it off.

Can I change the link after printing?

Not with a free (static) code, because the link is built into the pattern. If you think the link may change, use a Pro dynamic QR code, which you can redirect at any time.

Can I use them commercially?

Yes. Use them on menus, packaging, flyers and signs at no cost and with no attribution needed.

PNG or SVG?

PNG works everywhere. SVG stays sharp at any size, so it's best for printers and large signs.
