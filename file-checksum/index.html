    File checksum checker

    Calculate a file's MD5, SHA-1, SHA-256 and SHA-512 checksums and compare them with the one published by the download site, to check the file is genuine and complete.

    🔒 Runs in your browser. Nothing is uploaded.

    Your file's checksums will appear here.

    Software publishers often list a SHA-256 checksum next to downloads. If yours matches exactly, the file is genuine and wasn't corrupted during download.

    Questions

    Which checksum should I use?

    SHA-256 is the modern standard. MD5 and SHA-1 are fine for spotting accidental corruption, but not for security.
