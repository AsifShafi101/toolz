    Batch file renamer

    Rename hundreds of files at once with find and replace, numbering, dates and tidy formatting. Download renamed copies as a zip, or a one-click script that renames the originals.

    🔒 Runs in your browser. Nothing is uploaded.

    Preview

    Web pages can't rename files on your computer directly. Download renamed copies, or download the script, put it in the same folder and run it to rename the originals.

    Examples

    • Photos: pattern Wedding-{n} turns IMG_4821.JPG into Wedding-001.JPG.
    • Invoices: Invoice {date} {n} uses each file's date.
    • Tidy names: choose lowercase and replace spaces with - for web-friendly names.

    Questions

    Are my files uploaded?

    No. The renaming happens in your browser. Even the zip is made on your device.

    Is the script safe?

    It only contains rename commands for the files you chose, and you can open it in a text editor to check. On Mac/Linux it won't overwrite existing files.
