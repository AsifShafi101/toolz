    Website speed test

    Test any page's speed on mobile or desktop. You get Google's Core Web Vitals from real visitors (LCP, INP, CLS), PageSpeed scores and the top fixes.

    🌐 Sends the web address to Google PageSpeed Insights

    Core Web Vitals targets

    • LCP (loading): under 2.5 seconds
    • INP (responsiveness): under 200 ms
    • CLS (visual stability): under 0.1

    Google uses these as a ranking signal. The quickest wins are usually compressing images (try our image compressor), removing unused plugins and using good hosting.

    Questions

    Where do the results come from?

    Google PageSpeed Insights. Real-visitor data comes from the Chrome UX Report, and lab scores come from a Lighthouse test Google runs for you.

    Why do scores change between runs?

    Lab tests vary a little with network and server conditions. Look at trends rather than single numbers.
