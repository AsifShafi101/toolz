    Questions

    Is it really free?

    Yes. Free for any website, personal or business. Please keep the small “by etoolbox.co.uk” credit.

    Will the numbers stay up to date?

    Yes. The calculator loads from etoolbox, so when tax rates change each April your embedded version updates automatically.

    Does it work with WordPress, Wix and Squarespace?

    Yes. Paste the code into a Custom HTML block (WordPress), an Embed element (Wix) or a Code block (Squarespace).

    Do you track my visitors?

    No. There are no ads or tracking cookies in the embedded calculators.
