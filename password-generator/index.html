Password generator

Create strong, random passwords using your device's secure random generator. Passwords are made on your device and never sent anywhere.

Use a password manager to store your passwords safely.

What makes a strong password?

  • Length matters most. Aim for 16 or more characters.
  • Use a different password for every account, especially email and banking.
  • Turn on two-step verification wherever you can.
  • The UK's National Cyber Security Centre also recommends 'three random words' for passwords you need to remember.

Questions

Is it safe to generate a password online?

This generator runs only on your device using its built-in secure random number generator. The password is never sent over the internet.

What does 'bits' mean?

Bits measure how hard a password is to guess. Each extra bit doubles the guesses needed. Over 70 bits is strong.
