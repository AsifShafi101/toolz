    Duplicate file finder

    Choose a folder to find identical files, even if they have different names. See how much space you'd free. Files are compared on your device using SHA-256 fingerprints.

    🔒 Runs in your browser. Nothing is uploaded.

    Choose a folder (including its sub-folders) to scan. Nothing is uploaded.

    How it works

    1. Files are grouped by size. Files with different sizes can't be identical, so this is fast.
    2. Files with the same size get a SHA-256 fingerprint, which only matches if the contents are byte-for-byte identical.
    3. Each group lists one file to keep and the duplicates you can safely delete.

    For safety, this tool never deletes anything. Use the list (or the CSV) to delete duplicates yourself.

    Questions

    Does it find similar photos?

    It finds exact duplicates only, i.e. the same file saved twice, even with different names. Edited or resized copies count as different.

    How big a folder can I scan?

    Tens of thousands of files work fine. Very large files (over 512 MB) are compared by sampling, and these are labelled.
