# etoolbox.co.uk

Free QR code tools for UK small businesses. This is a plain static site: no build step, no server and no database.

## Tools
| Category | Pages |
|---|---|
| QR codes | `/qr-code-generator/`, `/menu-qr-code-generator/` (+ A6 table card), `/wifi-qr-code-generator/`, `/vcard-qr-code-generator/`, `/whatsapp-qr-code-generator/` |
| Invoices & quotes | `/invoice-generator/`, `/quote-generator/` (live A4 preview, VAT, print/save as PDF, details remembered in the browser) |
| Calculators | `/vat-calculator/`, `/profit-margin-calculator/`, `/hourly-rate-calculator/`, `/percentage-calculator/` |
| Images | `/image-compressor/`, `/image-resizer/`, `/image-converter/` (JPG/PNG/WebP, batch, in the browser) |
| Text | `/word-counter/`, `/case-converter/`, `/password-generator/` |

Every tool runs in the visitor's browser; nothing is uploaded.

## Settings
Edit `assets/config.js` to set:
- `contactEmail`
- `proMonthlyCheckoutUrl` / `proYearlyCheckoutUrl`: paste your Stripe Payment Links here. While these are empty, the Pro buttons say "Join early access" and open an email instead.

## Deploy (free) on Cloudflare Pages
1. Go to Cloudflare dashboard → **Workers & Pages → Create → Pages → Connect to Git** and pick this repo.
2. Framework preset: **None**. Leave the build command empty. Set the output directory to `/`.
3. After it deploys, open **Custom domains** and add `etoolbox.co.uk`.
4. Optional: turn on **Web Analytics** (free, no cookies), then submit `https://etoolbox.co.uk/sitemap.xml` in Google Search Console.

## Files
- `assets/app.js`: QR tools + shared Pro/contact links
- `assets/calc.js`, `invoice.js`, `image.js`, `text.js`: the other tools
- `assets/qrcode.js`: QR encoder by Kazuhiko Arase (MIT licence)
- `assets/style.css`: all styles

## Editing pages
Pages are generated by `_build/build.py`. Edit the Python files there, run `python3 _build/build.py`, and commit the result. `_build/test*.js` are Playwright end-to-end tests. `_build` is not published to the website.
