# etoolbox.co.uk

Free online PDF, image, document and money tools for UK small businesses. A static site (generated by `_build/build.py`) served by a small Cloudflare Worker for the few server features.

## Worker (`_worker/index.js`)
Everything is static except `/api/screenshot`, `/api/dns` (DNS-over-HTTPS to 8 public resolvers), `/api/logo` + `/logo/*` (KV),, which uses Cloudflare Browser Rendering (`BROWSER` binding in `wrangler.jsonc`). The Workers Free plan includes 10 minutes of browser time per day. Screenshots are cached for 24 hours on custom domains. Only public http(s) sites are allowed (no IPs, localhost or internal hosts).

**Yearly maintenance:** tax rates live in `assets/calc.js` (`TAX`, mileage rates, `BH_EW` bank holidays). Update them each April and re-run the tests.

Every tool runs in the visitor's browser; nothing is uploaded.

## AI background remover
- Model: ISNet general-use (DIS, **Apache-2.0**) from the rembg releases, dynamically quantised to int8 (46 MB) and split into `assets/models/isnet-q8.part0/1` (Workers assets have a 25 MiB per-file limit).
- Runtime: ONNX Runtime Web 1.31 (`assets/vendor/ort/`, MIT), wasm backend, proxied to a worker. Model bytes are cached with the Cache API (`etb-models-v1`).
- `_headers` makes `/background-remover/` cross-origin isolated (COOP `same-origin` + COEP `credentialless`) so ORT can use multiple threads. The ORT files also send COEP/CORP, which Chrome needs for the worker.
- int8 was chosen over float32 because ConvInteger is ~1.6× faster than float Conv in wasm; masks match float32 at IoU 0.97–0.998 on test photos.
- To change the model, rename the files (they're cached as immutable for a year) and update `MODEL_PARTS`/`MODEL_BYTES` in `assets/bgremove.js`.
- Avoid models with non-commercial or AGPL licences (BRIA RMBG, @imgly/background-removal).

Edit `assets/config.js` to set:
- `contactEmail`

## Deploy (free) on Cloudflare Pages
1. Go to Cloudflare dashboard → **Workers & Pages → Create → Pages → Connect to Git** and pick this repo.
2. Framework preset: **None**. Leave the build command empty. Set the output directory to `/`.
3. After it deploys, open **Custom domains** and add `etoolbox.co.uk`.
4. Optional: turn on **Web Analytics** (free, no cookies), then submit `https://etoolbox.co.uk/sitemap.xml` in Google Search Console.

## Editing pages
Pages are generated by `_build/build.py`. Edit the Python files there, run `python3 _build/build.py`, and commit the result. `_build/test*.js` are Playwright end-to-end tests. `_build` is not published to the website.

## Pro licences
Pro features (currently: your logo on invoices and quotes) unlock with a key like `ETB-XXXX-XXXX-XXXX-XXXX`, which our Worker checks against the **etoolbox-pro** KV namespace (`PRO` binding).
1. After a customer pays, run `python3 _build/make-pro-key.py customer@email.com 12` (12 = months).
2. In Cloudflare, go to **Workers & Pages → KV → etoolbox-pro → Add entry** and paste the printed KV key and value.
3. Email the customer their key. They enter it on the Pricing page (or when they first download an invoice with a logo).
4. To cancel a key, edit its value and add `"revoked": true`. Devices re-check keys daily.

## Usage counter & feedback (D1 database "etoolbox", binding `DB`)
- Every visit (once per browser session per page) and every real use (download, print, copy, or a few seconds of working with a tool) adds 1 to real counters. Bots and requests without our header aren't counted.
- Each tool page has a 👍/👎 box with an optional comment. A prompt appears once after someone first uses a tool.
- Counters only appear on the site once the real number passes `showSiteCounterFrom` / `showToolCounterFrom` in `assets/config.js`. Ratings appear after `showRatingFrom` votes.
- **Read feedback:** Cloudflare → Workers & Pages → D1 → etoolbox → Console:
  `SELECT tool, CASE vote WHEN 1 THEN '👍' ELSE '👎' END AS vote, comment, datetime(ts/1000,'unixepoch') AS time FROM feedback ORDER BY ts DESC LIMIT 100;`
- **Usage by tool:** `SELECT key, n FROM counters ORDER BY n DESC;`
